# 🔧 Configuração ESP32 SpO2 Random

## 📋 Pré-requisitos
- ESP32 DevKit V1
- Arduino IDE com biblioteca ESP32
- Bibliotecas: WiFi, HTTPClient, ArduinoJson

## ⚙️ Configurações Necessárias

### 1. Credenciais Wi-Fi
Edite no código:
```cpp
const char* ssid = "academico.street.br";  // Seu nome de rede
const char* password = "sua_senha";        // Sua senha
```

### 2. IP do Servidor
Edite no código:
```cpp
const char* serverURL = "http://172.20.10.7:3001/api/sensor-data";
```

### 3. Intervalo de Envio
Edite no código:
```cpp
#define INTERVALO_ENVIO 5000  // 5 segundos (em ms)
```

## 🚀 Como Usar

1. **Abra o Arduino IDE**
2. **Carregue o arquivo**: `ESP32_SPO2_RANDOM.ino`
3. **Configure as credenciais Wi-Fi**
4. **Verifique o IP do servidor**
5. **Faça upload para o ESP32**
6. **Abra o Serial Monitor (115200 baud)**

## 📊 O que o Código Faz

- ✅ Conecta ao Wi-Fi automaticamente
- ✅ Gera valores aleatórios de SpO2 (90-100%)
- ✅ Envia dados para a API a cada 5 segundos
- ✅ Mostra status no Serial Monitor
- ✅ Pisca LED para indicar status
- ✅ Detecta baixa saturação (< 95%)
- ✅ Reconecta automaticamente se Wi-Fi cair

### LED indica:
- **1 piscada**: Dados enviados com sucesso (normal)
- **3 piscadas**: Alerta de baixa saturação
- **5 piscadas**: Erro na comunicação

## 🛠️ Personalização

### Alterar faixa de valores:
```cpp
int spo2 = random(90, 101);  // 90-100%
// Para 85-100%: random(85, 101)
```

### Alterar intervalo:
```cpp
#define INTERVALO_ENVIO 3000  // 3 segundos
```

### Alterar pino do LED:
```cpp
#define LED_PIN 2  // LED interno
// Para LED externo: #define LED_PIN 13
```

## 🚨 Solução de Problemas

### Wi-Fi não conecta:
- Verifique SSID e senha
- Verifique sinal da rede
- Reinicie o ESP32

### Dados não chegam na API:
- Verifique se o backend está rodando
- Verifique o IP do servidor
- Verifique logs do Serial Monitor

### LED não pisca:
- Verifique se o pino está correto
- Verifique se o LED está conectado
