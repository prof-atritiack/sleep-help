🔗 Gerador de QR Code - Sleep Help

Gere um QR code personalizado para os visitantes da exposição acessarem seu projeto!


📋 Instruções para Impressão:

  1. Clique em "Baixar QR Code" para salvar a imagem
  2. Imprima em papel de qualidade (recomendado: 300 DPI)
  3. Tamanho recomendado: 10x10 cm para fácil leitura
  4. Cole em um local visível na exposição
  5. Teste o QR code antes da exposição!

💡 Dicas para a Exposição:

  • Coloque o QR code em uma altura confortável para leitura
  • Adicione instruções: "Escaneie para acessar o projeto"
  • Tenha um dispositivo de demonstração funcionando
  • Prepare uma versão offline caso haja problemas de internet
